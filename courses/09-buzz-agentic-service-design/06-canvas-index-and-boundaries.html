Course 09 — BUZZ for Agentic Service Design

The Canvas index and honest boundaries

The engagement's last BUZZ-side act is the Canvas: one channel-scoped document that indexes the portfolio — charter, phase state, roster, artifact register, and the planned-but-unpersisted kinds. It is generated from the store, not typed by hand.

Render → set → get → verify

# 1. render the index from the project store
node scripts/buzz-canvas-index.mjs render \
  --project-dir ~/.asd/projects/northfield-follow-up-care-5e167990 \
  --channel sd/northfield-followup-care \
  --channel-id 7909e866-74ef-4ef2-827b-649119aa972e \
  --fictional --planned persona-set --planned service-blueprint

# 2. set it on the channel
buzz canvas set --channel $CH --content - < canvas/northfield-followup-care.md

# 3. read it back and verify the hash round trip
buzz canvas get --channel $CH > retrieved.md
node scripts/buzz-canvas-index.mjs verify \
  --canvas-dir ~/.asd/projects/canvas --retrieved retrieved.md

verify compares the retrieved document's content hash against the rendered manifest: "ok": true is the round-trip proof. The set itself was event 0e691fd907c2bacc… — recorded in the session receipt alongside the channel create event and every reply event.

Note what the Canvas says about itself, in its own boundary section: "This Canvas is a navigation index over persisted ASD records. A row here is navigation, not proof." The Canvas points; the store proves.

What this course proved — and what it did not

Claim Status in this session
Private channel with 13-member roster live, receipted (create + membership events)
Runtime-authored replies from mentioned roles live, signed by role pubkeys
Fail-closed evidence handshake live (block, audit, verify, resume)
Store artifacts Critic-passed to final live, receipted (a202338b…)
Human phase gate with approval receipt live (nf-gate-discover-1, discover→define)
Canvas set/get round trip live, hash-verified
Unmentioned roles posting did not happen — by design
In-app Canvas panel pixels reconstructed frames only (this course labels them)
ACP agent spawning across hosts record-only / fail-closed; not claimed

The discipline generalizes: publish exactly what your receipts show, label reconstructions as reconstructions, and leave silent roles silent.
