Course 05: Living Journey Mapping & Mental Model Alignment

Generating Verbatim-Backed Journey Maps with Derived Emotional Sentiment & Indi Young Cognitive Ladders

Construct living customer journey maps and Indi Young mental-model alignments anchored in immutable evidence. Encode emotion as quote-gated node fields, derive sentiment views honestly from those fields, map multi-channel touchpoints, identify failure demand, and execute in-place remediation as versioned artifact lineage — the living map is a versioned artifact chain, not a live-sync daemon.

Paradigm Shift 01 / 10

Maps That Stay Alive

  • A journey map exported once to PDF is already lying; a living map re-validates against its evidence.
  • Every node cites verbatim evidence; every emotion field is derived, not guessed in a workshop.
  • Maps are artifacts in the store — patched in place, re-gated, re-rendered.
  • When the register changes, the map and its sentiment curve change with it.
Evidence register→ journey-map artifact→ Critic re-gate→ Living render (SVG/HTML)
"A map that defends itself changes how organizations argue."

Module 05.3 05 / 10

Anatomy of an Evidence-Gated Journey Map: Verbatim Anchors & Channels

  • journey-from-transcripts contract: inputs evidence-set min 3; acceptance min-nodes 3, min-evidence-per-node 1.
  • field-non-empty rules: every node carries emotion and touchpoint — enforced at write.
  • Nodes are {id, label, evidence[], fields}; edges and references are optional but typed.
  • outputKind journey-map; the contract also declares handoff and humanCheckpoints.
evidence-set (≥3)→ Method contract→ Nodes + edges + fields→ journey-map (accepted)
"Every node cites; every emotion is derived; every map can defend itself."
Module 05.4 06 / 10

Mathematical Derivation of Dynamic Sentiment Curves from Verbatim Evidence

  • Sentiment is computed from valence and intensity in the verbatim evidence, then plotted per phase.
  • Workshop guesswork curves are replaced by derivations a reviewer can audit node by node.
  • Change the evidence and the curve changes — the map is a function of its register.
  • The emotion field is non-empty by acceptance rule: no ungrounded moods.
Verbatim evidence→ Valence × intensity→ Per-phase aggregation→ Auditable sentiment curve
"The curve is a function of the evidence — change the register, change the curve."
Module 05.5 07 / 10

Pinpointing Failure Demand Points & Touchpoint Transition Hotspots

  • John Seddon: failure demand is demand caused by failing to do something right for the customer.
  • failure-demand-analysis separates value demand from failure demand across steps and channels.
  • Transition hotspots — channel handoffs — are where evidence density exposes root-cause friction.
  • Hotspots land as defect-ready findings, not workshop stickies.

Module 05.6 08 / 10

In-Place Remediation with sd_artifact_write & Interactive HTML Rendering

  • Patch journey nodes via sd_artifact_write; acceptance rules re-run on every write.
  • sd_review re-gates the patched map; vetoes loop back with mandatory fixes.
  • sd_export_artifact renders journey-map.<id>.svg; sd_export_report ships the dossier HTML.
  • Remediation is an edit to the system of record, not a new version of a dead file.
Patch node→ Acceptance re-run→ Critic re-gate→ Fresh SVG + dossier
"Patch, re-gate, re-render: the map stays alive because the loop stays closed."
