1. Theoretical Grounding & Literature Synthesis

Divergence with a paper trail

Vijay Kumar's 101 Design Methods (2012) frames ideation as Mode 5: Explore Concepts — and its first discipline is that concepts must be directly traceable to framed insights. Mode 5 is deliberately combinatorial: structured tools force the team beyond the first obvious idea, culminating in a Concept Catalog of distinct value hypotheses. The two canonical instruments this module operationalizes:

  • Morphological analysis (also catalogued in Universal Methods of Design): decompose the problem into independent dimensions (state carrier, exception actor, return timing), list options per dimension, and combine across dimensions. The matrix's power is coverage — it manufactures the combinations nobody would have proposed — and its weakness is volume: the combination count explodes and most combinations are worthless.
  • The NUF triple lens: score each surviving concept on New (does it create genuinely new value?), Useful (does it solve the framed problem?), Feasible (can this organization deliver it?). NUF is a convergence instrument: cheap, fast, and deliberately crude — it exists to kill combinations before they consume prototyping budget, not to pick winners precisely.

The two instruments are complementary halves of one loop: morphological analysis maximizes divergence inside a structure; NUF applies convergence without a meeting. The classic failure mode of machine-speed ideation is skipping the first half of Kumar's rule — high-velocity generation with no lineage back to insight. Volume without traceability is slop.

Every edge in that diagram is a typed, provenance-stamped reference stored in the artifact itself — not a claim in a slide deck. asd factcheck walks these references; a concept that cannot name its parent HMW set is structurally incomplete.

The morphological matrix as a constrained search space

Why agentic infrastructure

Human ideation at this volume collapses under bookkeeping, not creativity. The toolchain's contribution: (1) hmw-formulation fails closed without an insight-set — reframing cannot start from thin air; (2) acceptance rules force every HMW node to cite ≥1 evidence record (min-evidence-per-node 1) and carry a non-empty opportunity; (3) the NUF filter's scores live in a reviewable artifact (concept-set with numeric score, feasibility, risk), so the convergence decision is itself auditable — and the Critic's proposal rows are where the per-lens reasoning is recorded.

3. Schemas & Verified Execution

TypeScript schema (@asd/core)

// kind-schema for "hmw-set" (closed node fields):
//   question: string REQUIRED   insight: string   opportunity: string   theme: string
// relations: derived-from → insight-set | opportunity-matrix | experience-audit
//            supports     → opportunity-matrix | concept-set | prototype-plan
//
// kind-schema for "concept-set" (closed node fields):
//   concept: string REQUIRED
//   score: number      feasibility: number      risk: number      value: string      hypothesis: string
// relations: derived-from → insight-set | hmw-set | opportunity-matrix | value-proposition-canvas
//            supports     → prototype-plan | storyboard | value-proposition-canvas
export interface ConceptSetNodeFields {
  concept: string               // REQUIRED
  score?: number                // NUF composite — acceptance requires non-empty, placeholders forbidden
  feasibility?: number
  risk?: number
  value?: string
  hypothesis?: string
  description?: string
}

NUF filtering as Critic proposal rows

The convergence decision is recorded where all adversarial reasoning lives — in the review:

$CLI review --projectId juniper-collect-and-return-sprint-5cdce310 \
  --artifactId 6e05c4fc561a40ca87fad117582ea5f8 --verdict pass --rows '[
   {"rowKind":"proposal","severity":"low","message":"NUF-New: QR token is new to the store estate; courier pickup is established practice elsewhere.","evidenceId":"a5c1bd7c683e3669673f07feb77a081856999ee5c3d90ae79f20ab00fd29fa33"},
   {"rowKind":"proposal","severity":"low","message":"NUF-Useful: token directly removes the re-keying defect cited in int-01; courier does not address channel-switch state loss.","evidenceId":"5bf46f25c7a3018cd33c8ac6ea7ed1d5c1aa0bc4b644bcc9fb983623bed14ff4"},
   {"rowKind":"proposal","severity":"medium","message":"NUF-Feasible: existing scanners suffice for QR (risk 2); courier needs a logistics partner (risk 4). Advance u1, park u2.","evidenceId":"342f1b85b0fdb70dfc8010b87358f9b6da576edaef4f93f39d357d8ac018e509"}]'
# → {"status":"final","verdict":"pass"}

A veto on an unjustified score would look like: {"rowKind":"defect","severity":"high","message":"score 4.3 has no feasibility basis","fix":"cite scanner capability evidence or lower feasibility","rule":"nuf-feasibility"} — every defect row must carry a fix, and the artifact stays draft.

Worked example: The full chain from tensions to a selected concept

Fixture — three evidence-backed tensions from the Northfield follow-up research:

Tension Statement Evidence id
T1 Callback latency (median 62h) lands outside the 24h window when patient anxiety peaks d89ed8d2…
T2 Ward nurses spend ~40 minutes per patient chasing GP confirmation cfbee89a…
T3 Three portals duplicate data entry, so follow-up records silently diverge fa43b10e…

Step 1 — HMW prompts. Reframe each tension as a question; every node cites its tension's evidence:

{"kind": "hmw-set", "nodes": [
  {"id": "h2", "label": "Confirmation as byproduct",
   "evidence": [{"evidenceId": "cfbee89ae36a9ae181d6b9e449a185e94364f8d48bc2ca9f67247366285b8ed1"}],
   "fields": {"question": "How might we make GP confirmation a byproduct of documentation rather than a chase?", "opportunity": "Remove the 40-minute chase from every follow-up", "insight": "Nurses re-enter facts the GP already holds"}}]}

Step 2 — 6-3-5 brainwriting. Six participants write three ideas each per round for five rounds, sheets rotating so each round builds on the previous: up to 90 raw candidates in 30 minutes, and the handwriting forces building over talking. Round-1 excerpt for H2:

Participant Idea A Idea B Idea C
P1 GP co-signs the discharge note once shared follow-up register callback slot booked at discharge
P2 (building on P1) co-signature auto-closes the loop register readable by all 3 portals SMS shows the booked slot

Step 3 — 10-plus-10 on the top HMW. For H2, list the first ten ideas without judging (co-signing, shared register, pre-booked slot, fax-free GP feed, nurse-practitioner sign-off…), then deliberately produce ten more — patient self-confirms in the GP practice app, pharmacy-mediated confirmation, GP list batch-confirmed overnight…. The second ten is where the non-obvious combinations live; two of the three finalists below came from it.

Step 4 — NUF scoring (1–5 per lens, composite = mean):

Concept New Useful Feasible Composite Decision
Pre-committed callback slot + shared register 4 5 4 4.3 advance
GP co-signature workflow 3 4 2 3.0 park
Pharmacy-mediated confirmation 5 2 2 3.0 park

Step 5 — selected concept, written as a scored concept-set node:

{"kind": "concept-set", "nodes": [
  {"id": "c1", "label": "Pre-committed callback",
   "evidence": [{"evidenceId": "d89ed8d27665486f7c07ef6871b8c8016fe28aaf7a346c6a77c21de6972a0e38"}],
   "fields": {"concept": "Callback slot booked before discharge, recorded once in a register all three portals read", "score": 4.3, "feasibility": 4, "risk": 2, "hypothesis": "A visible, pre-committed slot removes the anxiety window and the 40-minute chase"}}]}

Interpretation: the chain's value is that each stage constrains the next — H2 exists only because T2 has evidence, and c1 advances only because its scores are numbers the Critic can compare against the parked alternatives. The 10-plus-10 discipline matters because the first ten ideas are the ones the room already believed; divergence that never leaves the obvious is not divergence.

4. Case Study Lens: Concept Briefs at Forge Industrial (Article 18)

Synthetic illustration — not a production log. Article 18 (Concept Briefs & Value Propositions: Funding Predictive Care at Forge Industrial) is an illustrative composite.

Forge's predictive-care program nearly died in a committee that could not compare twelve loosely-described ideas. The composite account's turnaround was exactly this module's chain: insights reframed as HMW questions, a morphological pass that manufactured combinations (including the eventual winner — remote sensor triage staffed by existing field engineers — which no one had proposed in open brainstorming), and a triple-lens filter that parked seven combinations in one afternoon. The funding committee never saw the seven; they saw three scored concepts whose lineage — insight → question → combination → score — could be walked node by node. That walkability is what derived-from references plus sd_factcheck give you for free.

$CLI artifact-write --projectId <pid> --methodId hmw-formulation --title "<title>" \

$CLI artifact-write ... --methodId nuf-triple-lens-filter --nodes '<numeric score, feasibility, risk>'
$CLI review --projectId <pid> --artifactId <nufId> --verdict pass --rows '<NUF lens proposals, evidence-cited>'

Deliberate fail-closed demo

asd method-run: method "nuf-triple-lens-filter" requires at least 1 artifact input of
kind concept-set; project has 0. Produce the typed input artifact before starting.

And writing a NUF node with "score":"N=4 U=5 F=4" (string) fails schema validation: fields.score must be number. The filter demands computable scores.

Verification checklist

  • HMW set: ≥3 nodes, each with question, non-empty opportunity, ≥1 evidence citation.
  • derived-from chain walkable: concept-set → hmw-set → insight-set.
  • NUF scores numeric; no placeholder values; Critic review rows carry the three lenses.
  • sd_factcheck --projectId <pid> exits 0.

Key Takeaways

  • Machine-speed ideation is only safe when divergence is structured (morphological) and convergence is scored (NUF) — with lineage enforced at write time.
  • hmw-set → concept-set → prototype-plan is a typed reference graph, not a narrative; sd_factcheck walks it.
  • The NUF filter's reasoning belongs in Critic proposal rows — convergence is a reviewable decision.
  • Placeholder scores and string scores are rejected; the filter demands numbers it can compare.
