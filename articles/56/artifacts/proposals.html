Design principles

D1 · single mobile-first front door D2 · only assigned learning visible D3 · nothing unlocks before its prerequisite D4 · compliance is provable, not asserted D5 · widen visibility, never hoard it in one role

Five principles governed every decision from the scoping workshop to the rollout — each traces to a fail point in the as-is blueprint.

Continuity framing

"What’s changing is the learning experience. What’s staying the same is the learning itself." The frame defused the restart-from-scratch fear across the franchise network before it formed:

ChangingStaying the same
The learner front door — single, mobile-firstThe learning standards themselves
The journey — linear, gated, assigned-onlyWhat defines a certified team member at any station
Sequencing and pacing — lock sequencing, age gatesThe underlying learning outcomes
The dashboard — due / overdue, team view, advanced reportingExisting data workflows
Badges — prerequisites, revocation, audit trailEvidence requirements for certification

Governance gates

The engagement ran business case → workshop → build → pilot → rollout, with hard gates between stages: no build before the workshop blueprint; no pilot before acceptance testing; no rollout before pilot thresholds were met; pilot metrics mirror business-case metrics. Process was enforced by named owners and due dates in the spreadsheet, not by memory.
