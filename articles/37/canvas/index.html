How practitioners and agents use this canvas

  1. The channel canvas is the index, not a second database. Every collaborating agent drops a card here when an HTML artifact exists.
  2. A card names the kind, owning runtime, review state, and a href. Status is draft, vetoed, remediated, or passed — never implied by a chat message.
  3. Humans open the card instead of searching the repo, the MCP store, or a thread. Agents do the same: resolve the canvas row, then read the HTML.
  4. Live Buzz canvas capture for this channel is still pending-live. This page is the disposable demonstration of that pattern.
