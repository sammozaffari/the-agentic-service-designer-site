This screen vs the old errors list

Design principle D5 — few hard stops, visible warnings

Before: 214 warnings, cleared daily

The old warnings list piled up so high managers stopped actioning it. It read as noise, so it produced no behaviour change.

After: one actionable alert, timed

One live entitlement, one countdown, one action. The compliant path is cheaper than the workaround, which is the design principle that protects 100,000+ boundary shifts.
