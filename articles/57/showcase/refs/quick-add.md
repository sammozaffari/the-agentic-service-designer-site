# Quick Add, pattern references

| Pattern | Reference | Taken | Rejected |
|---|---|---|---|
| Mobile report flow: a short list of large tappable categories, then a calm confirmation | [Clubhouse, Report an issue](https://mobbin.com/flows/5de4e383-75ee-49ef-9073-1a5b11881c89) | Large tap targets written as sentences; one action pinned to the bottom; a confirmation that says what happens next | The emoji celebration on submit |
| Reporting something about a place, with the location already known | [Apple Maps, Report an incident](https://mobbin.com/flows/b2ae1786-5fc7-44e2-a9b7-47c599e0b6fd) | The context the app already holds is never asked for; the sheet names the category with its icon | Map context, which a restaurant does not need |
| Condition against event, as two separate entries | [Google Maps, Adding a report](https://mobbin.com/flows/43be898e-75de-4464-a7c2-621404aa0b27) | Separate paths for two things people confuse, each with its own short question set | Community moderation framing |
| The status of the person's own last request, carried on the home screen | [Hers, home with a request in review](https://mobbin.com/screens/e36b5e4e-8334-43c8-a1a4-4f71ea9f8043) | A single outcome card above the routine action, in plain words, with a tick rather than a progress bar | The promotional stack beneath it |
| Worked examples where the hesitation is, rather than a help link | [Intercom, Help Center](https://mobbin.com/screens/dfa39e1e-71de-4850-8459-c9fe4e5da2da) | Examples in the reader's own language, on the deciding screen | Hero imagery and a search-first layout, which belongs in the knowledge base |
