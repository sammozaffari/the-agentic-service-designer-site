# Pattern references: area-manager dashboard

Searched on Mobbin on 17 September 2026 before the screen was built. Each row: the pattern, the reference, what was taken and what was rejected.

| Pattern | Reference | Taken | Rejected |
|---|---|---|---|
| Many locations compared in one table, metrics grouped under a shared header, one row per location | [Navan, COVID-19 status by state](https://mobbin.com/screens/691ae050-b43b-44b2-9687-471bca63dd9a) | Location as the row, metric columns grouped under a labelled header, a per-row action at the right edge, a view switch above the table | Alphabetical sort, which buries the rows that need attention; a download icon on every row |
| Small multiples: one panel per item, same scale on each, a plain-language line under the grid | [Xero, business snapshot](https://mobbin.com/screens/7c69264d-fc91-4bd1-aa80-d09890ca2706) | A grid of equally sized panels, a dashed line for the comparison series, a stated shared scale, and a sentence that says what the shapes mean | Financial ratio framing; per-panel info icons |
| Sparklines set inside a dense data table so shape and number read together | [PlanetScale, query insights](https://mobbin.com/screens/ef455d28-04ea-46f4-a289-cb6c283ea929) | An inline bar in the row so volume is comparable down the column without a second chart | A column-picker menu; latency percentile vocabulary |
| Stat tiles with a linked drill-down above the main table | [Airtable, projects dashboard](https://mobbin.com/screens/53a16902-f7a3-47f5-859e-20cd4891e72d) | Four tiles, each with a link into the list it counts, and a one-line breakdown beneath the number | Marketing tiles and trial banners |

## What the references did not answer

None of the sources showed a leading indicator presented as a ratio, or a comparison table sorted so the weakest rows sit first. Both come from the research rather than from a pattern: zero reports was already treated as a signal to check in, and the reminder email listed period-to-date counts per restaurant without saying which ones mattered.
