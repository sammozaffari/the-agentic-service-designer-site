# Pattern references: Contractors

Searched on Mobbin on 17 September 2026 before the screen was built. Task: an ideal-state contractor module for a restaurant safety system.

| Pattern | Reference | Taken | Rejected |
|---|---|---|---|
| Compliance register with status counts above a filtered table | [Deel, Compliance documents](https://mobbin.com/screens/9f5af254-f966-4810-adbb-c428854523e3) | Counts of what needs attention sitting above the table and doubling as filters; one status badge per row; a per-row action so the fix starts from the row | The bulk-message workflow and the payroll columns, which are administration rather than site safety |
| Check-in list with who is here and who is not | [Sweatpals, Check-in](https://mobbin.com/screens/a12748ab-e2c1-407b-8625-8b1ba6f1db0b) | Checked-in state as a first-class column, and chip counts that split the list by that state | The dark theme and the per-person visit counter, which answer a question nobody on a shift asks |
| An at-a-glance strip before the full list | [Luma, Guests](https://mobbin.com/screens/77625847-95c6-46b2-b900-1b8647c84ed4) | Naming who is on site right now above the register, with the sign-in action attached to that strip | The capacity and invitation framing |
| Register table with a right-hand detail drawer | [Navattic, Visitors](https://mobbin.com/screens/79a31934-4ca2-4700-86a5-c180fa735404) | The drawer opening over the table so the manager keeps their place in the list | The deprecation banner and the properties tabs |
