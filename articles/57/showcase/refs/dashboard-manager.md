# Manager dashboard, pattern references

| Pattern | Reference | Taken | Rejected |
|---|---|---|---|
| Dashboard with stat tiles, a chart and a table beneath | [Airtable, Projects dashboard](https://mobbin.com/screens/53a16902-f7a3-47f5-859e-20cd4891e72d) | Four tiles each with a linked drill-down, a chart and a table below, one card per question | Marketing tiles and trial banners |
| A workflow strip that reads left to right as the day does | [Jobber, Home workflow strip](https://mobbin.com/screens/9de47309-e37f-40db-b3c8-847d17392de7) | Today's work grouped by what needs a person, with the action on the row | Revenue widgets |
| Action tracker with owner, due date and inline completion | [Vanta, Action tracker](https://mobbin.com/screens/9106887f-2b5f-4d68-813d-13944f9a368d) | A primary create button at the top of the sidebar; grouped navigation with section labels | The risk-scenario column |
| Status and severity as chips on a list of incidents | [incident.io, incident list](https://mobbin.com/screens/1d72b14c-95e4-4d38-affb-039c4dc40139) | Status as a chip on every row, counts on the navigation | Engineering severity vocabulary |
