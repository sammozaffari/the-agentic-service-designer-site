# Corrective actions: pattern references

Searched on Mobbin on 17 September 2026 before the screen was built.

| Pattern | Reference | Taken | Rejected |
|---|---|---|---|
| Board columns with counts, a collapsed done column | [Linear, Issues board](https://mobbin.com/screens/fc208a44-dbf9-4f79-b9b0-db57f9840964) | Column header with a count; the Done column shown but visually quieter; card with an identifier, title and a meta row; hidden columns listed at the edge | Engineering labels and cycles |
| Cards with a red overdue date, priority and due date | [ClickUp, Board view](https://mobbin.com/screens/0c287f59-753c-4e28-92ad-9dff95fcde36) | Overdue date shown in red on the card itself; owner avatar and due date on the same meta row | Tag clouds, cover images, priority flags |
| Status-tinted columns with an item count in the header | [Slack, Lists kanban](https://mobbin.com/screens/fd3b9b17-1333-427b-b93b-5152cdc39f8b) | Column header reads "Status · n items"; one primary add button for the whole board | Star-rated priority; column tints (too loud beside the semantic reds and ambers) |
| Board insights panel: work items that need attention, due, stuck | [Jira, Board insights](https://mobbin.com/screens/8fadb82e-c19c-4892-a2c5-978804acdd28) | A short "needs attention" notice above the board that names the overdue items | A separate insights panel; kept it to one line |
| Task table with assignee, due date and inline complete | [Vanta, Action tracker](https://mobbin.com/screens/9106887f-2b5f-4d68-813d-13944f9a368d) | The list view: one row per action with owner, due, status and an evidence column | Risk-scenario column |
