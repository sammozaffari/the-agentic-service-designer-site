Report threshold quick reference

Decision support · answers the "is it worth reporting?" filter

Component · when to report it
1Minor
A spill, a scrape, a near miss

No first aid. If it is a hazard or a near miss, report it so it can be fixed before it hurts someone.

Report itIf it could recur, or someone could get hurt next time.
2Moderate
First aid was given

A cut, a minor burn, a bruise. First aid was needed, so it always gets reported.

Report itAlways. This is the default line: when in doubt, file it.
3Serious
Needs attention today

A burn, a deep cut, a chemical splash, a dangerous condition. Report today, not at the end of the week.

Report itToday. Tell your manager as soon as it is safe to do so.
4Critical
Emergency

A severe burn, a fall from height, an unconscious person. Get help first, report when it is safe.

Report itAs soon as safe. Delaying is expected here, not a breach.

Each threshold carries a number, a label, and a plain-language "report it" line. The highlighted Moderate column uses a border and background, but the decision is readable without it. No severity is communicated by colour alone.
