# Portfolio shell: pattern references

Searched on Mobbin before the home, Work and About pages were rebuilt. Each row records the pattern, the reference, what was taken and what was left. Links open on Mobbin.

| Pattern | Reference | Taken | Rejected |
|---|---|---|---|
| Case-study header: small eyebrow in the margin, large quiet display title, one-line subtitle, then the work at full width | [COLLINS, San Francisco Symphony](https://mobbin.com/sites/sections/213b1c6a-6655-4330-965d-4851cf1e25cd) | The eyebrow set small and far left of a large title; the subtitle as a single line; artefacts flush and full width beneath | Centred titles and a serif display face, which would fight the interface work |
| Programme header with a carousel of full-bleed imagery | [COLLINS, Brand Refresh](https://mobbin.com/sites/sections/6dcc8739-5445-4f4c-bfcd-7572ff663125) | The generous space above the title, and the artefact given the full column | The carousel, which hides work behind an interaction |
| A single editorial statement, then an asymmetric grid of work with a tag and one line under each | [Instrument](https://mobbin.com/sites/sections/05811dd7-a07a-41ae-9fa7-192b8eede1b1) | The statement as the opening move rather than a paragraph of positioning; a tag, a title and one line per project | The asymmetric sizing, which implies a hierarchy the cases do not have |
| Point-of-view sentence followed by a three-up work grid with captions beneath | [Wild](https://mobbin.com/sites/sections/bd58336d-6de6-4678-aafd-10089a509897) | Two-line statement, supporting paragraph, then a flush three-up grid; the title and one-line description sitting under the image, not over it | The coloured tool pills under each card, which read as decoration here |
| Work index: page title left, facets as plain text to the right, then a flush grid | [MOUTHWASH Studio, All Work](https://mobbin.com/sites/sections/5ed7b943-1b00-4ccf-bfe3-50897107642b) | The facet list as quiet text rather than buttons; the grid running edge to edge under it | Two facet dimensions, which is more sorting than eight projects need |
| Index with a tag column and mono captions under each thumbnail | [MOUTHWASH Studio, Index](https://mobbin.com/sites/sections/7ea4ce8e-8811-462e-b5d9-f27d7c3e4ec6) | Mono micro-labels under artefacts; a neutral ground behind each thumbnail so the artefact sits on it rather than bleeding | The dark canvas, which would invert the reading pages |
| About page: large title pinned left, body text in a narrow column to the right | [Pentagram, About](https://mobbin.com/sites/sections/326ff8e0-1f06-4a08-a915-0e53b4967529) | The two-column split with the title held left and a measured column of prose right; no ornament at all | The single block of text with no capability structure underneath |
| About page with a large statement and portraits beneath | [TinyWins](https://mobbin.com/sites/sections/04eaf97e-e0d8-43c5-a6b2-995a5d519238) | The portrait given a defined frame and a caption rather than floating | The saturated full-bleed colour field |
| Full-bleed 3D art direction as the opening | [Unseen Studio](https://mobbin.com/sites/sections/1bdc4e01-2f7e-4e09-9aa1-27f02c13bcbe) and [Anima](https://mobbin.com/sites/sections/3eb3a78b-89a6-41b2-b563-fcb6fd94c2ee) | Nothing | Rejected outright: a rendered hero would swamp the artefacts, and the artefacts are the argument |
| Company statement with a photograph and a floating text card | [Voiceflow](https://mobbin.com/sites/sections/476948d0-ff0e-4b44-8aa6-05ec5e93a231) | The idea that the statement carries the scale of the work, not adjectives | The text card over the photograph, which costs legibility |
