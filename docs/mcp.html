The MCP server

asd-mcp exposes the same runtime as the CLI and DSH Studio: the canonical 29 sd_* tools, method and artifact metadata, canvas/orchestration records, and fact-checking. It speaks newline-delimited JSON-RPC 2.0 over stdio. The emitted bundle inlines runtime dependencies and includes pack-local metadata; it does not require npm install, a global executable, or a sibling suite checkout.

Start the server

The server is published as a standalone repository with its bundled corpus:

TERMINAL
git clone https://github.com/imehr/asd-mcp.git
node asd-mcp/mcp/bin/server.mjs

That checkout is regenerated from this monorepo by scripts/publish-distribution-repos.mjs; its provenance.json records the source commit. From a source checkout, emit a disposable pack and invoke the server by absolute path:

TERMINAL
node platform/compiler/emit-packs.mjs --output /tmp/asd-packs
node /tmp/asd-packs/mcp/mcp/bin/server.mjs

The standalone pack's asd-mcp.json is intentionally project-relative:

DATA
{
  "mcpServers": {
    "asd": {
      "command": "node",
      "args": ["mcp/bin/server.mjs"]
    }
  }
}

Because clients choose their own working directory, replace the relative path with an absolute path after copying the pack. The server launcher does not use PATH fallback. ASD_WORKSPACE still controls the runtime project's file root; ASD_BOOKS_ROOT, ASD_ARTICLES_ROOT, and ASD_AGENTS_ROOT control the served corpus and role-prompt roots independently.

Client configuration

Claude Code loads the plugin-root .mcp.json automatically:

DATA
{
  "mcpServers": {
    "asd": {
      "command": "node",
      "args": ["${CLAUDE_PLUGIN_ROOT}/mcp/bin/server.mjs"]
    }
  }
}

OpenCode uses its local command array:

DATA
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "asd": {
      "type": "local",
      "command": ["node", "mcp/bin/server.mjs"]
    }
  }
}

Codex merges the project-level MCP block or uses its registration command:

TERMINAL
codex mcp add asd -- node "$PWD/platform/packs/codex/mcp/bin/server.mjs"
TOML
[mcp_servers.asd]
command = "node"
args = ["mcp/bin/server.mjs"]

Kimi's project mirror uses .kimi-code/mcp.json and a project-root relative path. See host packs for complete copy and trust steps.

Protocol lifecycle

Send initialize once before tools/list, tools/call, resources/list, or prompts/list:

DATA
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18"}}

The response advertises tools, resources, and prompts, with server asd-mcp version 0.1.0. Notifications are not answered. tools/call returns MCP content blocks and isError: true for runtime/tool failures; protocol framing stays valid. Default tool timeout is 30 seconds and the frame limit is 1 MiB.

tools/list returns each name, description, and JSON inputSchema. tools/call validates the same schema used by the CLI. Evidence is limited to quote, telemetry, and document; artifact writes persist failed acceptance as draft records, while dangling evidence pointers fail closed. A pass review must have an evidence-cited proposal row and a veto must include a defect with a fix.

Resources: 226 when corpus roots are present

resources/list exposes the pack's discovered books, chapters, articles, and metadata using asd:// URIs. It is cursor-paginated with a page size of 100:

NOTE
asd://books/<book>
asd://books/<book>/<chapter>
asd://articles/<NN>

The current receipt counts 226 resources, but a copied runtime without the repository corpus returns an empty list by design. This does not affect the 29 runtime tools. resources/read returns the exact UTF-8 payload, MIME type, version, size, and logical provenance, never an absolute local filesystem path.

Prompts: ten roles

prompts/list exposes orchestrator, researcher, synthesizer, mapper, ideator, prototyper, measurer, critic, presenter, and librarian. prompts/get returns the shared role contract followed by the role-specific instructions as one user message. Generic MCP clients can therefore use the same collaboration protocol even when they lack native subagents. Prompts are empty when ASD_AGENTS_ROOT is unavailable; this is an explicit corpus-root boundary, not a hidden fallback.

Errors

Code Meaning
-32700 invalid JSON
-32601 method not found
-32602 invalid params, unknown tool/prompt, bad cursor, or non-object arguments
-32603 unexpected internal handler failure
-32000 initialize required
-32001 tool call timed out
-32002 resource not found

Tool failures are returned as an isError MCP result with a structured runtime error. Unknown protocol methods are JSON-RPC errors. Cancellation uses $/cancelRequest; notifications remain silent.

ACP and agent execution boundary

The MCP surface can execute the canonical tool registry and record orchestration plans, dispatch attempts, handoffs, and human gates. The shared ACP envelope is asd-acp/1 with the supported capability record-only. host-agent-spawn is unsupported on the generic MCP surface and returns an explicit structured failure. A role prompt or an orchestration record is not proof that the host launched a new process. BUZZ and DSH integrations require their own live acceptance evidence.

Disposable verification

The release receipt verifies six emitted bundles (buzz, claude-code, codex, kimi, mcp, and opencode) from isolated HOME/PATH/cwd/workspaces:

  • initialize and clean stderr;
  • 29 tools;
  • 226 paginated resources;
  • 10 prompts;
  • project → evidence → artifact → evidence-cited review → factcheck;
  • no invocation of an ambient/global executable.

This proves pack-local interoperability. It does not claim that every listed host has installed or executed the pack in its native UI.

Format pin

MCP revision 2025-06-18; JSON-RPC 2.0; Node 20 or newer; bundle emitted by the suite compiler. See CLI for terminal use and ACP for the record envelope.
